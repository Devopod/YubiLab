YubiLab Documentation

YubiLab is a full-stack cloud IDE platform similar to Replit. Build, run, and deploy code directly from your browser with real-time editing, an interactive terminal, multi-language execution, and AI-powered assistance.

✍

Run Python, JavaScript, C, C++, Java, Go, PHP, and Rust.

🤖

YubiAI

AI-powered code generation, debugging, and autonomous project building.

Quick Start

1. Create a Project

From the dashboard, click "+ New Project". Choose a name, select a language, and click Create.

2. Write Code

Click on files in the Explorer to open them in the Monaco editor. You get full syntax highlighting, auto-save (2s debounce), and tab management.

3. Run Code

Click the Run button or press Ctrl+Enter to execute the current file. Output appears in the Console panel.

4. Use the Terminal

The terminal panel gives you a full interactive bash shell. Run any Linux command including package installs, git, file management, etc.

5. Ask YubiAI

Click the AI button to open the YubiAI panel. Choose an action (Generate, Debug, Explain, or Agent) and type your prompt.

Features

Project Management

  • Create projects with 9 language templates
  • Rename and delete projects from the dashboard
  • Auto-seeded sample project for new users
  • Each project gets its own isolated workspace directory

File System

  • Tree-based file explorer with directory support
  • Create, rename, delete files and folders
  • Right-click context menu for file operations
  • Auto-save on changes with 2-second debounce

Code Editor

YubiLab uses the Monaco Editor (the same engine that powers VS Code). Features include:

  • Syntax highlighting for 20+ languages
  • Bracket pair colorization
  • Code folding
  • Minimap navigation
  • Smooth cursor animation
  • Custom dark theme ("yubilab-dark")

Terminal

The integrated terminal provides a full Linux bash shell powered by xterm.js and node-pty. You can:

  • Run any bash command (ls, cd, mkdir, rm, etc.)
  • Install packages (pip install, npm install)
  • Use git commands
  • Navigate the file system
  • Run scripts and servers

The terminal starts in your project directory automatically.

HTML Preview

For HTML projects, click the Preview button to render your HTML/CSS/JS in an iframe. The preview auto-updates when you switch to the Preview tab.

YubiAI Assistant

YubiAI is powered by GPT-OSS 120B and provides:

  • Generate - Generate code from natural language descriptions
  • Debug - Analyze code and fix bugs automatically
  • Explain - Get clear explanations of code
  • Agent - Autonomously build entire projects from prompts

YubiAI understands the current file context. Select code to provide specific context, or it will use the entire file.

Autonomous Agent

The YubiAI Agent can autonomously create entire projects from a prompt. It will:

  1. Analyze your request and create a plan
  2. Generate all necessary files and folders
  3. Write complete, working code
  4. Suggest run commands

Switch to "Agent" mode in the AI panel, then describe what you want to build.

Example prompt:
"Build a Flask calculator app with add, subtract, multiply, divide operations"

Supported Languages

YubiLab provides starter templates for each language when you create a project:

  • Python - main.py
  • JavaScript - index.js
  • HTML/CSS/JS - index.html, style.css, script.js
  • C - main.c
  • C++ - main.cpp
  • Java - Main.java
  • Go - main.go
  • PHP - index.php
  • Rust - main.rs
  • Flutter / Dart - lib/main.dart, pubspec.yaml, web/index.html

Flutter / Dart

YubiLab supports Flutter for building cross-platform apps (Web, Android, iOS) from a single Dart codebase. Flutter SDK 3.24.5 and Android SDK 34 are pre-installed.

Creating a Flutter Project

Select "Flutter / Dart" when creating a new project. A starter Flutter app is generated with Material Design, including lib/main.dart, pubspec.yaml, and a web template.

Build & Export

Click the Build button in the editor toolbar to access the build menu:

  • Build Web App - Compiles to HTML/JS and auto-deploys to the preview panel. Test your app instantly in the browser.
  • Build Android APK - Compiles a release APK for Android devices. Download it when ready.
# Or use the terminal directly:
flutter build web      # Build for web
flutter build apk      # Build Android APK
flutter test           # Run tests

Download Builds

After building, use the Build menu to download:

  • Download APK - Downloads the compiled .apk file for Android installation
  • Download Web Build - Downloads a .zip of the web app for self-hosting

The web build is automatically served in the Preview panel so you can test it live without downloading.
